# Bloom Proof

Bloom over doom isn't a slogan. It's a testable claim. Here's the proof.

Bloom Proof is a permanent, open, community-built public record of AI doing real work for real people. Every entry is the same shape: a real problem, a working AI solution, open code or open weights, and a human it actually helped.

## The one rule

No working artifact, no entry. Takes don't ship.

## Why this exists

Centralized platforms get acquired. Hugging Face sold to Nvidia for $13B in 2026. Every centralized platform is one acquisition away from closing the doors. What we build here is open and permanent — nobody can buy it, nobody can shut it down, because nobody owns it.
